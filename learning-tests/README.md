# Learning Tests

This folder is for Playwright tests used for self-learning and experiments.

Run only these tests:

```bash
npm run test:learning
```

Run them with the browser visible:

```bash
npm run test:learning:headed
```

Open Playwright UI mode for this folder:

```bash
npm run test:learning:ui
```

Regular project tests still live in `tests/` and run with:

```bash
npm test
```
